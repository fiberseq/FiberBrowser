# Synchronise regions

The lab pack registers the analysis panel, temporary anchor-pick ruler and browser-store extension. Saved frames become matched-region peak rows. Cluster consumes their block maps; Footprints and NFRs offer Selected matched regions in the shared region picker.

`model.ts` defines frames: every window has the same frame length (the refined template stretch) and a block map, `blocks: {frame: [u0, u1), genomic: [g0, g1)}` with equal lengths; on `+` frame u0 is genomic g0, on `-` it is g1 - 1. A rigid window is one block. A chained window has several (an insertion is genomic bases with no frame position, a deletion frame positions with no genomic base). One panel may contribute several copies (`copy: 'a' | 'b' …`, shown as W3a, W3b; key `panelId#copy`). On a circular contig (`contigLength`) start/end and blocks are logical and may pass the contig length (across the origin); blocks are split at every multiple of it, so each block is one reference interval and BED export (`frameBedRows`) writes one BED6 row per block with frame coordinates in extra columns. Frames saved before block maps restore as one rigid block per window. `syncState.ts` exposes `getActiveFrame()` and `useActiveFrame()`. Search state (job, results, selection, copies, cluster check) lives in `panelState.ts`, a non-persisted store, so a remount (full view, dock) keeps the map; a session import clears it. Thresholds live in `settings.ts` (per viewer, localStorage).

Backend routes (current workspace only):

- `POST /api/lab/region-sync/jobs`: windows, metrics, `minimum`, `thresholds` (`profileSupport`, `profileAloneR`, `profileAloneZ`, `sequenceCover`, `maxIndel`), `allPairs` (default true); returns a queued job.
- `GET /api/lab/region-sync/jobs/{id}`: state, progress, notes, proposals, per-read coverage, `timings`, `diagnostics` (what minimap2 and each profile returned per pair).
- `DELETE /api/lab/region-sync/jobs/{id}`: cancellation.
- `POST /api/lab/region-sync/cluster`: frame `length`, windows with `key`, strand and block map, `k`, `minCover`; the clustering check.

Loading uses interval geometry and the nucleosome layer only (no deamination parsing) and caches each window per session; profiles use a stable sample of at most 3,000 reads, counts use all reads.

Proposals. Sequence: minimap2 asm20 (both strands, secondary hits) lines are split at indels above the chain limit (`maxIndel`, default 2 kb), then collinear segments are chained across gaps up to it (dynamic programming on aligned bases, best chain first, each segment once): one proposal with its blocks, gaps and indel totals. Copies of a region stay separate proposals and are flagged as repeated. Anchors and whole-window profile shifts (only when r ≥ `profileAloneR` and z ≥ `profileAloneZ`, and not contradicted by ≥ 90%-identity sequence over `sequenceCover`) are rigid single-block proposals.

Internal repeats. One ticked window runs “Find repeats in this window”; every multi-window search also searches each window against itself. Overlapping windows on the same reference/contig exclude the forward zero-offset alignment and show “Same sequence in both windows — showing repeats within it”. The sequence search self-aligns the union of overlapping windows with minimap2 `-DP` (same sequence names), asm5 and 11-base seeds, then clips to each window. Local alignments stay separate; indels over min(10 bp, `maxIndel`) split them so adjacent copies do not chain through their linkers. Reciprocal self-hits are deduplicated. Defaults are 200 aligned bp and 90% identity, adjustable in Advanced; repeat identity includes indel bases. At least half a match must lie in informative 64-base tiles (3-mer entropy ≥3.5 bits), rejecting homopolymers and short tandem repeats. Shape self-search masks offsets closer than `shapeWidth` before choosing each seed's best match, including NFR landmarks.

Repeat blocks share a single window lane, with returning ribbons (crossed for inverted copies). Connected copy components appear once in the list (“3 copies”); copy nodes use the existing multi-way triangle check. Inconsistent components start unchecked; removing conflicting members can make a smaller selection acceptable. Sequence-supported copies remain grouped when chromatin differs; the original per-metric disagreement stays visible. Selection composes block maps through intermediate copies where needed and preserves gaps and orientation. Accept saves W1a/W1b/W1c, including a labelled template copy, through the existing matched-region/session path. Internal groups of a non-template window can also be accepted. Copies and matches to other windows share one block row and can be accepted together.

`tests/e2e/lab/sync-repeats.spec.ts` generates a synthetic three-copy BAM/FASTA in a temporary directory, then finds, accepts and opens the copies as panels.

Chromatin shape (local) (`shape`): accessibility, ≥175-bp gap (NFR) fraction and nucleosome occupancy on the 10-bp grid, z-scored per window, bins covered by fewer than max(10, a quarter of the median) sampled reads masked. Seeds of `shapeWidth` ×1/×2/×4 (300/600/1,200 bp) from window B (stride a sixth of the seed, at least 100 bp, plus seeds centred on B's NFR peaks) against every position of A on both strands, as one matrix product per width (each channel unit-normalised and stacked, so a dot product is the mean channel r). z: against the best match of the same seed in 12 phase-randomised copies of A (the same random phases for every channel, so autocorrelation and channel dependence are kept; per seed mean, SD floored at the pooled SD); a match must also beat every seed's best match in every null copy of that width (a family-wise ceiling over the seed search). Kept at r ≥ `shapeMinR` (0.6) and z ≥ `shapeMinZ` (4) when centred on an NFR peak on both sides, z ≥ `shapeMinZ` + 2 otherwise; chained by offset into blocks. NFR landmarks (each B NFR's best A NFR, ±150/300 bp) are reported in the "nothing found" note and proposed only with `shapeLandmarks`. Shape proposals are rigid, flagged `chromatin-only`, and flagged `contradicted-by-sequence` when sequence places the stretch elsewhere. It takes 0.2–1.0 s per pair; unrelated amplicons give no proposal at the defaults.

Scoring: every requested metric scores each proposal along its block map: sequence (identity; share of the extent aligned ≥ `sequenceCover`), anchor (1/0), accessibility and NFR shape (local Pearson r over the extent widened to 1 kb by the end blocks' offsets, window shifted ±300 bp; supports at r ≥ `profileSupport`), shape (mean channel r over the extent itself; supports at r ≥ `shapeMinR`). Status: agreement needs two lines of evidence (sequence, anchor, chromatin; accessibility, NFR and shape are one), single-metric, disagreement (support and disagreement), weak. Confidence is the weighted mean support (sequence identity × share; chromatin metrics r 0.1 → 0, 0.6 → 1, at half weight).

Circular contigs: a window covering a whole turn is aligned twice over, template and window alike; chains running into a second turn keep their best turn, duplicates (rotated or partial) are dropped, and coordinates past the contig end mean across the origin. Profiles index such windows modulo their length. Any circular window can be rotated (a one-turn logical window starting elsewhere); a crossing proposal offers Rotate for the side that crosses.

Map (`SyncMap.tsx`): “Each vs template” lanes or “All windows” (the default for 3+ windows, stacked by greedy similarity). A chain is one ribbon of blocks (gaps and notches are indels); chromatin-only ribbons are hatched. Each member bar is a button: click or Space/Enter toggles it, arrows move focus, and Escape clears the selection. Drag across lanes to select intersecting members in all windows; Shift or Command adds to the current selection. Checkboxes and map share one selection.

Multi-way blocks (`blockSelection.ts`, using `multiwayBlocks`): cross-window matches and internal repeats form one graph of physical stretches (window × copy). Aligned overlap joins stretches within a window; triangle checks flag conflicting positions. Consistent blocks start with every member checked. A row has a block checkbox, individual member checkboxes, and a Refine action. Selection composes block maps through intermediate members, preserves gaps and orientation, and does not require the original template. A missing alignment or conflicting triangle is explained in one line beside the selection.

“Accept selected blocks” saves all selected valid rows together, one correspondence per row. “Merge selected blocks into one group” concatenates compatible ordered maps into one frame; incompatible directions or ordering are refused before any frame is written. Acceptance is one Undo step. Accepted frames use the existing session extension; the draft search and checkbox selection survive panel remounts and reset on session import. No additional routes.

`tests/e2e/lab/sync-multi.spec.ts` covers three-window map/keyboard/drag selection, acceptance of two blocks, and Undo.


Accepted frames create durable matched-region peak rules. Each block is drawn on the peak row in every panel at its locus and reference; click selects its partners, and hover outlines the group. The panel follows the steps (windows → find → matches → refine and save): setup folds to a line after Find, the checklist to "Comparable ✓"/"N issues", clustering and Advanced are folded. Refine: template start/end, copies per window (multi-select), flips (reverse a window along the frame). Reads count when they cover at least the chosen share (default 80%) of a window's mapped bases. The clustering check maps every read base through the block map into frame bins.

Deliberately deferred: chaining for profile-only and chromatin-shape proposals (they stay rigid), scaled frames, motif/frozen-class/SV metrics, read-panel crop overlays and scaled display across indel gaps. Aligning on accessibility/NFR can make those signals agree by construction. Reference keys are retained, but v1 does not fingerprint replacement reference files under the same key.

Tests: adjacent vitest files, `tests/lab_tests/test_region_sync.py`, and the demo-BAM Playwright spec `browser/frontend/tests/e2e/lab/sync-regions.spec.ts`.

Cluster on selected matched regions uses `/api/lab/cluster-regions`, with per-window references and oriented block maps. Open as panels gives each region an independent panel and its own assignments; without those panels, copy a supplies the read-panel assignments and composition charts retain every copy. The shared region model and clustering position overrides provide the seam for pooled Footprints/NFR work.

## Region analyses

`POST /api/lab/region-classes` submits rigid equal-width windows to the existing consensus job queue. It loads each region on its dataset’s reference, aliases datasets per window, and uses FiberHMM `pool_payloads` / `orient_unit`. There is one discovery call for the group. The engine retains one deterministic window per physical molecule; the UI states that counting rule. Frozen transfer uses the chosen completed run’s catalog and excludes training molecules. Genomic provenance remains in the artifact; the browser builds genomic indexes alongside the frame indexes, including reversed chemical strands and class edges. Import and session restoration retain the source-dataset mapping.

Gapped and circular block maps offer “Use the longest shared block”: intersect all windows’ frame blocks, split at the origin, and create a new rigid group from the longest shared interval meeting Minimum aligned length. The original group and orientations are retained. NFR inference accepts a pooled payload, but its molecule/result schema drops genomic-window provenance and its downstream sequence, motif, membership and drawing tools assume one locus. The safe fallback queues ordinary NFR jobs per region/dataset with `nfr_regions`, retaining each result and drawing it in its own panel. The region cards compare counts, variant bounds and open fractions without claiming shared variant identities. The queue continues across panel remounts while the browser page stays open; reloading the page keeps submitted jobs but does not submit the remaining windows.

Typed Footprints regions, given NFR regions and ruler highlights offer Link as matched. Peak-row drawing retains the existing context-menu action. Linking into a selected rigid group extends it and preserves partner orientation; widths are cropped to the narrowest region, as in manual linking. Analysis outlines use the same dashed ruler/read treatment, label placement and Clear wording, in each analysis’s existing colour family.

Open as panels is available on the matched row, its context menu, saved groups, and the matched Cluster result. Panels use a common span and padding, template first, with per-panel Reverse for oriented copies. The shared group strip closes the panels and restores the previous layout. Group membership and the previous layout travel in the panel configuration through sessions and Undo. Hovering a panel outlines its region. Reverse is also available in any panel header in Per panel mode; linked navigation continues to use global Reverse. Gapped regions retain genomic spacing (they are mirrored, not warped to the frame).
