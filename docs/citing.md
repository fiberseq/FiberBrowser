# How to cite

If you use FiberBrowser in published work, please cite **FiberBrowser** and **FiberHMM**, which calls the chromatin
footprints FiberBrowser shows.

- **FiberBrowser** (this repository): the full reference, with its version, is in
  [CITATION.cff](../CITATION.cff) (GitHub's *Cite this repository* reads it), e.g.
  *FiberBrowser Authors. FiberBrowser: a genome browser for single-molecule chromatin data (Fiber-seq and DAF-seq),
  version 3.0.0. https://github.com/fiberseq/FiberBrowser*
- **FiberHMM**: https://github.com/fiberseq/FiberHMM (its own CITATION.cff; documentation at
  https://fiberseq.github.io/FiberHMM/).

Please give the FiberBrowser version you used (the About box and the toolbar's **⋮ → How to cite** say it, and so
does a saved session's `fiberbrowser_version`).

## In the app

- **About FiberBrowser** (the app menu) and the toolbar's **⋮ → How to cite** give the citation, with a button to copy it.
- **Exported figures** carry a small citation line at the foot: *Made with FiberBrowser 3.0.0
  (github.com/fiberseq/FiberBrowser) · please cite FiberBrowser and FiberHMM*. It is on by default; turn it off
  with **Citation line** in the Export panel (remembered in this browser).

## Data you identify with it

Identify searches a TE library: the bundled *D. melanogaster* canonical transposon set (Bergman lab / FlyBase, CC0)
or Dfam's curated families for other species. Cite the library you used too; Identify's report names it with its
version and citation.
